# $bog_yard

Быстрое подключение к мастерам Гипер Базы. Штатный `$giper_baza_yard` перебирает мастера по одному и ждёт отказа каждого, `$bog_yard` открывает сокеты гонкой с разносом `stagger` (300 мс): побеждает первый открывшийся, остальные закрываются, номер победителя запоминается в `master_cursor` и следующее подключение начинается с него.

Список мастеров штатный: сид общей сети, переопределение `#!giper_baza_yard_masters=`.

## Подключение

В веб-бандле модуль подменяет `$giper_baza_yard` сам, достаточно подключить его в `*.meta.tree` приложения:

```tree
include \/bog/yard
```
